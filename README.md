# Bex Trivia 🎂

A birthday trivia game for Adria, all about Bex. Plain HTML, CSS and JavaScript, so there's nothing to install or build.

## Make it yours

Open `questions.js` and edit:

- `QUESTIONS`: the trivia. `answer` is the index of the right option (0 = first).
- `LETTER`: the letter in the envelope revealed after the candles are blown out.

## Preview

Double-click `index.html` to open it in a browser.

## Put it online (GitHub Pages)

1. Push to GitHub.
2. On the repo, go to **Settings → Pages**.
3. Under **Source**, choose **Deploy from a branch**, then pick `main` and `/ (root)`.
4. After a minute it's live at `https://zineb-selmouni.github.io/bday/`.
